## Problem

### Dynamic Student Greeting Using Servlet and JSP
### Aim

Create a simple web application using Servlet and JSP that accepts student details and dynamically displays a personalized greeting.

### Problem Statement

Create a Java web application named  **Student Greeting Application**.

The application must contain a JSP form that accepts:

- Student name
- Course name

When the user submits the form, a Servlet must read the entered values and forward them to another JSP page.

The result JSP must dynamically display the following message:

Welcome `<student-name>`!
You are enrolled in the `<course-name>` course.

### Your Task
- Complete result.jsp File.
- Complete GreetingServlet Class.
- No Need to pom.xml, all the required dependencies are already added
### Sample 1:
Input
Output

```
Student Name: Harsh Kumar
Course Name: Java Web Development
```

```
Welcome Harsh Kumar!
You are enrolled in the Java Web Development course.
```
