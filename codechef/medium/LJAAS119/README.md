### Sum of numbers

Write a program using a for loop to calculate the sum of the first 10 natural numbers.

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-03T15:02:24.244Z  

```java
class Codechef
{
	public static void main (String[] args) 
	{
		int sum = 0;
        for (int i = 1; i <= 10; ++i) {
            sum += i;
        }
        System.out.println(sum);
	}
}

```
