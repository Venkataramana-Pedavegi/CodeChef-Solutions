## Problem

### Client-Server Architecture Level

In a typical database architecture where a client application directly communicates with a database server without an intermediate application server, which term best describes this setup?

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-27T14:13:59.032Z  

```cpp
Two-tier: Client directly communicates with the database server.

Three-tier: Client communicates with an application server, which communicates with the database.

Main difference: Three-tier architecture has an additional application/business logic layer, making it more scalable and maintainable.
```
