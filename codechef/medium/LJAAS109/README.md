### Print Squares

Write a program that utilizes a while loop to print the squares of numbers from 1 to 5.

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-02T14:43:46.897Z  

```java
class Codechef
{
	public static void main (String[] args) 
	{
		int num = 1;
        while (num <= 5)
        {
           System.out.print(num * num + " ");
           num++;
        }
	}
}

```
