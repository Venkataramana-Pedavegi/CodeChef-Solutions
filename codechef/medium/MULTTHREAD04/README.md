# MULTTHREAD04

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

### Dual Style Multithreading

Java supports creating threads in two common ways:

- By implementing the Runnable interface.
- By extending the Thread class.

You are given an integer $N$. Your task is to complete the given program so that two separate threads generate counting messages from $1$ to $N$.

### Task

You are given three incomplete parts in the template.

You must complete them as follows:

- In MyRunnable.run(): Generate the message RunnableTask - Count: i for every $i$ from $1$ to $N$. Store each message in the provided StringBuilder output. Each message must end with a newline.
- In MyThread.run(): Generate the message ThreadTask - Count: i for every $i$ from $1$ to $N$. Store each message in the provided StringBuilder output. Each message must end with a newline.
- In main(): Create an object of MyRunnable. Create a Thread object using the MyRunnable object. Create an object of MyThread. Start both threads using start(). Wait for both threads to finish using join().
### Input Format

The input contains a single integer $N$.

### Output Format

Print:

- $N$ lines generated by MyRunnable.
- $N$ lines generated by MyThread.
- The final message Both threads completed.
### Sample 1:
Input
Output

```
3
```

```
RunnableTask - Count: 1
RunnableTask - Count: 2
RunnableTask - Count: 3
ThreadTask - Count: 1
ThreadTask - Count: 2
ThreadTask - Count: 3
Both threads completed.
```

### Explanation:

For $N=3$, both threads process values from $1$ to $3$.

The `Runnable`-based thread stores three `RunnableTask` messages, while the thread created by extending `Thread` stores three `ThreadTask` messages.

The `join()` method ensures that both threads finish before their stored results are printed.

## Solution

**Language:** Java  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-21T14:00:23.411Z  

```java
import java.util.*;

class MyRunnable implements Runnable
{
    private final int n;
    private final StringBuilder output;

    MyRunnable(int n)
    {
        this.n = n;
        this.output = new StringBuilder();
    }

    @Override
    public void run()
    {
        for (int i = 1; i <= n; i++)
        {
            output.append("RunnableTask - Count: ")
                  .append(i)
                  .append("\n");
        }
    }

    String getOutput()
    {
        return output.toString();
    }
}

class MyThread extends Thread
{
    private final int n;
    private final StringBuilder output;

    MyThread(int n)
    {
        this.n = n;
        this.output = new StringBuilder();
    }

    @Override
    public void run()
    {
        for (int i = 1; i <= n; i++)
        {
            output.append("ThreadTask - Count: ")
                  .append(i)
                  .append("\n");
        }
    }

    String getOutput()
    {
        return output.toString();
    }
}

class Codechef
{
    public static void main(String[] args) throws Exception
    {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        MyRunnable runnableTask =
            new MyRunnable(n);

        Thread runnableThread =
            new Thread(runnableTask);

        MyThread threadTask =
            new MyThread(n);

        runnableThread.start();
        threadTask.start();

        runnableThread.join();
        threadTask.join();

        System.out.print(runnableTask.getOutput());
        System.out.print(threadTask.getOutput());

        System.out.println("Both threads completed.");

        sc.close();
    }
}
```
